# Generative AI Internship Portfolio

This repository contains selected Generative AI, NLP, and Machine Learning projects developed during my internships and learning journey.

## Projects

### 1. Streamlit Local LLM Interface

A private local AI chatbot built with Streamlit and Ollama. The application supports local open-source LLMs, conversation history, and real-time response streaming.

**Technologies:** Python, Streamlit, Ollama, Requests

### 2. AI Document Assistant

A Retrieval-Augmented Generation (RAG) application that allows users to upload documents and ask questions based on their content.

**Technologies:** Python, Streamlit, LangChain, Google Gemini, HuggingFace Embeddings, FAISS

### 3. Customer Support Chatbot

An NLP-based customer support chatbot that matches user queries with relevant FAQ responses using TF-IDF and Cosine Similarity.

**Technologies:** Python, Flask, Pandas, Scikit-learn, NLP

### 4. AI MCQs Generator

An AI-powered application that generates Multiple Choice Questions (MCQs) from a topic or uploaded PDF using LangChain and Groq LLM.

**Technologies:** Python, LangChain, Groq, Llama 3.1, Streamlit, PyPDF, ReportLab
